# 松獅犬主角身份規格 v1

狀態：已由使用者確認「很像」，可作為第一版生產參考；笑臉表情 v2 亦已核准。

## 固定身份特徵

- 犬種：松獅犬
- 毛色：暖金紅／橘棕色，鬃毛與身體毛色有自然深淺變化
- 口鼻與胸口：較淺的奶油灰色，胸前有明顯厚鬃毛
- 頭部：寬、方、圓厚的頭型，短而寬的口鼻
- 耳朵：小型圓三角耳，部分被鬃毛遮住
- 鼻子：黑色
- 體型：結實、厚重、短腿、緊湊，不要生成成細長型犬
- 尾巴：厚實、蓬鬆、向背部捲起
- 舌頭：張嘴時保留松獅犬特有的深藍紫色舌頭
- 整體質感：自然真實的厚鬃毛與毛流，不要塑膠感或過度卡通化

## 生成時的固定規則

- 不要把咖啡店、家具、項圈、衣服或其他配件當成角色身份的一部分。
- 每個新場景只改背景、光線、時間、構圖和細微動作；不要改犬種、毛色、體型、臉部花紋或尾巴。
- 先使用 `master-front-v1.png` 或 `master-3q-v1.png` 建立關鍵幀，再交給 WAN First/Last Frame 動畫。
- 透明 cutout 主要用於背景合成與比例校準，不直接取代動態生成的關鍵幀。
- 需要開心表情時，沿用 `smiling-face-v2.png` 的自然張嘴與藍紫色舌頭，不要生成誇張人類式笑容。
- 目前仍是 reference pack，不是專用 LoRA；若跨場景仍有明顯身份漂移，再評估訓練 LoRA 或加入更強的身份控制節點。
