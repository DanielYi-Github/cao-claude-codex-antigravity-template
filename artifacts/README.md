# Runtime Artifacts

Agents may write review notes, UI notes, schema observations, specifications, and test reports here. The directory is kept in the repository so handoffs have stable paths, but generated files are ignored by Git.

Expected files include `spec.md`, `architecture.md`, `review.md`, `ui-notes.md`, `schema.md`, and `test-report.md`.

Do not commit secrets, production data, credentials, cookies, or CAO logs.
